LLM Foundations: From Neurons to Large Language Models

Before understanding Large Language Models, we build the foundations layer by layer: the artificial neuron, multilayer networks, sequence models, attention, and the Transformer — the architecture every modern LLM is built on.

0/1 topics

1. Overview

A Large Language Model (LLM) is a neural network trained to predict the next token in a sequence — at massive scale. That single sentence hides decades of ideas: the artificial neuron, gradient-based learning, recurrent networks for sequences, the attention mechanism, and finally the Transformer architecture.

Understanding an LLM without these foundations is like reading the last chapter of a novel first. This chapter climbs the ladder one rung at a time, so that when we reach GPT-style models, every component feels inevitable rather than magical.

Predict the next token. Everything else in an LLM — architecture, training data, scale — exists to do that one thing extraordinarily well.

3. Foundations: The Basic Neural Network

3.1 The artificial neuron

The neuron computes a weighted sum of its inputs, adds a bias, and passes the result through a non-linear activation function:

y = f( w₁x₁ + w₂x₂ + … + wₙxₙ + b )

Common activations: sigmoid and tanh (historical), ReLU and GELU (modern deep networks). The non-linearity is essential — without it, stacking layers would collapse into a single linear function.

3.2 Multilayer perceptrons

Stack neurons into layers and you get an MLP. Each layer transforms its input into a new representation; deeper layers combine earlier features into increasingly abstract ones. A two-layer network with enough hidden units can approximate any continuous function (universal approximation), which is why neural networks are such a general tool.

3.3 Learning = backpropagation + gradient descent

Training adjusts the weights to reduce a loss function. Backpropagation applies the chain rule to compute the gradient of the loss with respect to every weight; gradient descent then steps each weight in the direction that reduces the loss. Nearly every neural network you will ever use — including LLMs — is trained by exactly this loop, just scaled up and distributed.

4. Modeling Sequences: RNNs, LSTMs, and GRUs

Language is sequential — word order matters. Recurrent Neural Networks process a sequence one token at a time, passing a hidden state forward that acts as memory:

hₜ = f( W·xₜ + U·hₜ₋₁ + b )

Plain RNNs struggle with long-range dependencies because gradients vanish or explode over many time steps. LSTMs and GRUs fix this with gates — learned mechanisms that decide what to remember, what to forget, and what to output. For years, LSTM-based encoder–decoder models were the state of the art in machine translation.

The limitation that remained: recurrence is inherently sequential. You cannot compute the hidden state for token 10,000 until you have processed token 9,999 — which severely limits how much hardware parallelism training can exploit.

5. Seq2Seq and the Attention Mechanism

Sequence-to-sequence models use one RNN to encode an input sentence into a context and a second RNN to decode it into another language. The original bottleneck: the entire input had to be compressed into a single fixed-size vector.

Attention removed that bottleneck. Instead of one fixed vector, the decoder learns, at each output step, a weighted combination over all encoder states — deciding dynamically which input words are most relevant. The weights are computed from query–key compatibility scores, normalized with softmax:

attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V

This single formula — queries, keys, values, scaled dot products — is the heart of every Transformer and every LLM.

6. The Transformer

The 2017 paper "Attention Is All You Need" removed recurrence entirely. The Transformer processes the whole sequence at once using self-attention: every token attends to every other token in the same sequence. Its key ingredients:

  • Token + positional embeddings — since there's no recurrence, position information is injected explicitly.
  • Multi-head self-attention — several attention operations in parallel, each free to learn different relationships (syntax, coreference, semantics).
  • Feed-forward layers — an MLP applied to each position independently; this is where much of the model's "knowledge" is stored.
  • Residual connections + layer normalization — keep gradients healthy in very deep stacks.

Because every token is processed in parallel, Transformers train orders of magnitude faster than RNNs on modern GPUs/TPUs — which is precisely what made scaling to billions of parameters practical.

7. From Transformers to Large Language Models

Two families emerged from the Transformer: encoder models like BERT (bidirectional, great for understanding tasks) and decoder-only models like GPT (autoregressive, great for generation). Modern LLMs are almost all decoder-only Transformers trained with next-token prediction on internet-scale text.

Three ingredients turned a good architecture into today's LLMs:

  • Scale — parameters, data, and compute grown together; capabilities improve predictably with scale (scaling laws).
  • Pretraining → adaptation — a general "foundation model" is pretrained once, then adapted with instruction tuning and RLHF to follow instructions and be helpful and safe.
  • Emergent behaviors — at sufficient scale, models show abilities like in-context learning and multi-step reasoning that smaller models do not.

Everything else in this series — prompting, RAG, fine-tuning, agents, evaluation — builds on this foundation model picture.

9. Example: A Neuron in a Few Lines

A single neuron with a sigmoid activation, implemented with NumPy — the atom from which LLMs are built:

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

x = np.array([0.5, -1.2, 3.0])   # inputs
w = np.array([0.8,  0.4, -0.6])  # learned weights
b = 0.1                          # bias

y = sigmoid(np.dot(w, x) + b)
print(y)  # ≈ 0.34

Scale this to billions of neurons, replace sigmoid with GELU, wrap it in self-attention and feed-forward blocks, train on trillions of tokens — and you have an LLM.
